Please refactor the integration tests in this project to modernize our testing stack and improve the robustness of our API contract testing. 

I need you to perform two main migrations across our integration test classes (e.g., classes ending in `*IT` or `*IntegrationTest`):

### 1. Migrate from MockMvc to RestTestClient
We are moving away from `MockMvc` to the newer, fluent `RestTestClient` introduced in recent Spring Boot versions. 
* Replace `@AutoConfigureMockMvc` with `@AutoConfigureRestTestClient`.
* Replace `@Autowired private MockMvc mockMvc;` with `@Autowired private RestTestClient restTestClient;`.
* Remove `throws Exception` from test method signatures.
* Convert `mockMvc.perform(...)` chains to `restTestClient.get().uri(...).exchange()` chains.
* If the tests use MockMvc's `.with(jwt())` for security, remove it. Instead, inject the mock token by adding `.header("Authorization", "Bearer mock-token")` to the request, and ensure the mocked `JwtDecoder` is configured in a `@BeforeEach` method to return a valid mock Jwt when decoded.

### 2. Replace JSONPath with Local Test Records
To ensure our tests act as strict API contract verifiers, we want to stop using brittle string-based `jsonPath` assertions. 
* Do NOT use our production application domain/DTO classes for requests or responses in these tests. 
* Instead, generate local Java `record` types at the bottom of the test classes to represent the exact Request and Response JSON structures.
* For responses: Deserialize the response into these local records using `.expectBody(LocalResponseRecord.class).value(response -> { ... })` and use AssertJ (`assertThat`) to verify the fields.
* For requests (POST/PUT): Instantiate a local record and pass it to the client using `.bodyValue(new LocalRequestRecord(...))`.

### Reference Example
Here is exactly how a test should look after your refactoring:

```java
// Setup and Annotations
@SpringBootTest
@AutoConfigureRestTestClient 
@ActiveProfiles("integration-test")
class ExampleControllerIT {

    @Autowired
    private RestTestClient restTestClient;

    @MockitoBean
    private JwtDecoder jwtDecoder;

    @BeforeEach
    void setUpMockJwt() {
        when(jwtDecoder.decode(anyString())).thenReturn(
                Jwt.withTokenValue("mock-token").header("alg", "none").claim("sub", "test-user").build()
        );
    }

    @Test
    void getExampleReturnsCorrectData() {
        restTestClient.get()
                .uri("/api/example")
                .header("Authorization", "Bearer mock-token")
                .exchange()
                .expectStatus().isOk()
                .expectBody(ExampleResponse.class)
                .value(response -> {
                    assertThat(response.id()).isEqualTo(1);
                    assertThat(response.status()).isEqualTo("ACTIVE");
                    assertThat(response.metadata().type()).isEqualTo("test");
                });
    }

    // Local records for strict contract testing
    record ExampleResponse(Long id, String status, Metadata metadata) {}
    record Metadata(String type) {}
}
